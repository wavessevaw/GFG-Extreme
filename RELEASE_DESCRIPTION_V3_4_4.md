## What's New in 3.4.4

- **Benchmark Apply:** Apply the measured TDP and native-FPS point to the current game and selected performance mode.
- **No immediate TDP reset:** Governor starts from the selected point instead of overriding it with the previous power limit. It can still adapt if performance requires.
- **HUD actions:** APPLY / DISCARD for a measured point; RETRY / DISCARD when there is no valid measurement.
- **Mode-specific profiles:** Save results independently for Quality, Balanced, Battery and Autopilot.
- **Engine unchanged:** GSF Kedavra 1.6.2 and frame-generation algorithms are unchanged.
