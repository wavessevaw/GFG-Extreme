## GFG Extreme 1.2.0

New: Frame OS (experimental), in Settings → Diagnostics.

- Observe and Shadow measure frame timing and input inside the game without changing anything
- Act (unlock it first) adds real frames while you move the camera or fight, and saves power in pauses and menus
- The Governor remembers what it learned across mode switches; a game's memory can be reset from Diagnostics
- Last session shows energy saved and how long the session ran in each mode
- Bug fixes and improvements

### Install
Download `GFG-Extreme-v1_2_0.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.
