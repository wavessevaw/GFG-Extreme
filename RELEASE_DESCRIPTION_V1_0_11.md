## GFG Extreme 1.0.11

Bug fixes and improvements.

- Battery and Balanced no longer raise TDP for short hitches that more power cannot fix
- Fewer repeated FPS dips from lower-power checks
- Diagnostics improvements

### Install
Download `GFG-Extreme-v1_0_11.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.

### Verify your download
SHA-256 of the zip: `<sha256>` (see `SHA256SUMS.txt`).
