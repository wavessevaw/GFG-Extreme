# 60 Hz display policy

Install GFG Extreme 3.5.0 through Decky, reinstall Gamescope in Setup and reboot. The bundled runtime version starts with kedavra-1.7.0. To roll back, install the official 3.4.4 ZIP, reinstall its engine, and reboot.

With generation enabled and the active screen at 60 or 59.94 Hz, GFG automatically targets 30 real FPS with ×2. This applies across performance modes, including Battery. A game FPS cap on a 90 Hz display does not trigger it. The same game session can switch displays. Camera Boost yields while the 60 Hz policy owns the target. The profile stays saved, Off is honored, and other refresh rates use normal control. The 30 FPS target does not guarantee 30 FPS from a heavy game.

The engine may advance to the real endpoint of a pair if a second intermediate would otherwise be displayed and the following position is available. Physical latency and panel pacing remain unverified. Resource Manager and its existing Engine panel are included.
