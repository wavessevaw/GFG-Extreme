## GFG Extreme Decky: Governor v0.0.8 (pre-release)

Bug fixes and improvements.

- Governor can be enabled while a game is running
- Overlay can be toggled live

### Install
Download `GFG-Extreme-Governor-v0_0_8.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.
