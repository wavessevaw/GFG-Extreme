## What's New in 3.4.0

- **GSF Kedavra 1.6.0:** Updated engine with Kedavra Focus.
- **Kedavra Focus:** Adaptive edge sharpening with halo protection.
- **Simplified Controls:** One ON/OFF switch in Graphics, fixed 100% strength.
- **Game Profiles:** Save Focus settings per game; CAS/DLS settings are restored when Focus is disabled.
- **Upscaler Independence:** No changes to FSR, XeSS, DLSS or OptiScaler.
- **GPU Efficiency:** Single-pass enhancement with no extra full-resolution buffers.

*Focus is SDR-only. HDR is bypassed.*
