## GFG Extreme 1.0.7

Bug fixes and improvements.

- Quality mode raises TDP again when a scene gets heavier
- Fixed a rare mid-game reset of the Governor
- More reliable fallback after a failed setting
- Fixed state carried over between games and modes
- Session summary fixes

### Install
Download `GFG-Extreme-v1_0_7.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.
