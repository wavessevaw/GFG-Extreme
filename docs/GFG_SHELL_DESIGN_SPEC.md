# GFG Shell: спецификация эталонов

Источник: два PNG, предоставленные заказчиком 13 октября 2026, по четыре экрана в каждом. Приоритет имеют изображения, а не прежняя CSS-тема. Целевая среда — Steam Deck OLED, Gaming Mode, 1280×800.

## Метод измерения и ограничения

Измерены границы восьми viewport внутри исходных листов 1586×992; подписи листа и наружные рамки не входят в экран. Для каждого viewport отдельно применяется x′=(x−x0)×1280/w, y′=(y−y0)×800/h. Исходные рамки имеют разные пропорции; это явно выбранная нормализация двух осей, а не утверждение, что исходник уже имел 16:10. Нельзя смешивать её с contain/letterbox при последующей сверке.

Координаты измерены по растровым границам вручную. Предварительная неопределённость — до двух пикселей исходного листа; после увеличения она может превышать целевой допуск. Таблица является рабочей геометрией и не выдаётся за доказательство уже достигнутых ±2 px. При визуальной реализации уточняются реальные границы скруглённых областей и субпиксельные края. Автоматическое совпадение с собственной таблицей не заменяет сравнение с PNG.

В `GFG_SHELL_REFERENCE_GEOMETRY.json` сохранены размеры, SHA-256 источников, crop bounds, коэффициенты и координаты областей. Локально созданы восемь ненормализованных вырезок `references/*-source.png` и восемь `*-1280x800.png`; это эталоны, не скриншоты продукта. Источники не используются как полноэкранная текстура приложения.

## Цвета и типографика

Измеренные медианы плоских проб: акцент RGB(252,7,0), фон RGB(10,10,12), тёмная панель RGB(23,24,27), клавиша RGB(37,38,43). Полные координаты проб находятся в JSON. Это локальные образцы градиентного растрового изображения: нельзя назначать всем элементам один цвет и считать Delta E00 пройденным. Старый #ff1608 не принимается автоматически за цвет эталона.

Названия игровых логотипов — реальные artwork, не подбор похожего системного шрифта. Семейство интерфейсного шрифта по PNG достоверно не установлено; проверяются габариты, baseline, насыщенность и переносы. Заголовки, подписи, подсказки и вторичные строки измеряются отдельно после размещения реальных данных. Длинные названия не должны сдвигать геометрию панели.

## Данные, действия и состояния

- Главная: artwork и recent из Steam, launch активной игры, дополнительные действия, реальный заряд и время. Градиент и логотип сохраняют места, даже если выбранная игра отличается от Control.
- Библиотека: реальные игры и количество, четыре колонки, две видимые строки эталона, фильтр installed/favorites, сортировка/прокрутка. Фокусная рамка не изменяет размеры карточки или соседей.
- Страница игры: игровые часы, достижения, cloud-status по доступным данным. GFG mode buttons связываются с реальным Governor и read-back; ни «18/46», ни «32 ч» не прошиваются.
- Быстрые настройки: отдельная правая панель, слева реальный игровой контекст; brightness/volume/network/GFG/sleep выполняют настоящие действия. Внешняя панель не становится произвольным полноэкранным чёрным overlay.
- Системные настройки: настоящая боковая навигация, дисплей/яркость/адаптивность/night/refresh/scale. Отсутствующая аппаратная возможность показана недоступной, без успешной имитации переключателя.
- Загрузки: реальный active download, speed/bytes/queue, pause/resume и накопитель. Нулевые/неизвестные значения различаются; перестановка очереди не имитируется локальным массивом.
- Меню: реальный пользователь/аватар/online state, настоящий маршрут каждого пункта, фон текущей игры. Фокус восстанавливается после закрытия.
- Клавиатура: реальное поле и результаты поиска, языки, IME, backspace/shift/symbols/submit/space. Реальная Steam keyboard semantics сохраняется, а не заменяется демонстрационным onclick.

Для каждого экрана обязательны pointer/gamepad focus, нажатие, disabled, pending, error и длинные строки. Для switches нужны проверенные on/off; для навигации — selected/focused раздельно. Анимации не создают повторных RPC; при reduced motion движение отключается без потери состояния.

## Протокол визуальной приёмки

Вход: exact commit + модель устройства + SteamOS/Steam/Decky versions + Gaming Mode 1280×800 + реальные PNG восьми экранов и видео взаимодействия. Chromium fixture не может удовлетворить этот вход.

Для каждого экрана сохранить reference, device screenshot, overlay 50%, difference map, geometry.json с измеренными bounds, mask.json с основаниями исключений и metrics.json. Сохранять исходники и SHA-256; не ретушировать capture, не переносить в него части эталона.

IoU=A∩B/A∪B рассчитывается для каждой ключевой области; порог ≥0.98, без усреднения, скрывающего провал. Максимальное отклонение каждой из четырёх границ ≤2 px. CIEDE2000 (sRGB→D65 Lab) для основных плоских цветов ≤3. Указывать метод агрегации и распределение, не только среднее. Карту отличий не использовать как единственную метрику, поскольку разные реальные игры дают другое содержимое artwork.

Маски разрешены только для внутреннего содержимого динамического artwork/чисел/аватара/часов. Их рамки, размещение, размеры и промежутки не маскируются. Нельзя исключить из проверки весь экран, панель, controls или focus. Проверяется также отсутствие очевидных композиционных нарушений человеком.

Текущий результат: эталоны и рабочая геометрия подготовлены. Реальных capture, overlay, difference maps и измерений достигнутого соответствия ещё нет. Визуальная приёмка **не пройдена**. Препятствие описано в GFG_SHELL_ENVIRONMENT_BLOCKER.md.
