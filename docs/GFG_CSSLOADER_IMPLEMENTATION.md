# GFG SteamOS через CSS Loader: состояние реализации

14 октября 2026. Основа изменений: d7813449c6119ac9643aba8b3ced8c8730290d37,
ветка feature/gfg-steamos-shell-20261013, draft PR #128. Stable 2.1.1 не изменяется.
Новые требования пользователя разрешают CSS Loader вместо собственного транспорта.
Предыдущие архитектурные документы остаются историей разработки, а не описанием
завершённой реализации. Макеты — визуальная цель, а не доказательство совместимости.

## Реализовано в коде

- Manifest v9 GFG-SteamOS, отдельные CSS-файлы восьми семейств экранов, scoped
  selectors без зависимости от data-gfg-shell. Окна SP/Big Picture, MainMenu,
  QuickAccess и SteamKeyboard обслуживает CSS Loader.
- Art Hero (исследован v3.2.03) и Clean Gameview (v1.7) подключены зависимостями
  с проверенными именами параметров. Switch Like Home одновременно не подключается.
  REQUIRE_NAV_PATCH нужен для скрываемых зависимостями элементов навигации.
  CSS Loader не фиксирует версии зависимостей: проверка установленных версий обязательна.
- Цвета, фокус, карточки, кнопки, слайдеры, меню и панель GFG оформлены в чёрно-красной
  палитре. Progress bars, состояние переключателей, размеры виртуализированной сетки
  и обработчики действий остаются под управлением Steam.
- Компактная React-панель GFG в существующем разделе Decky: Autopilot, приоритет
  auto/battery/smoothness, Frame Fusion, Continuous Boost, переходы к показателям
  и настройкам. Только существующие RPC, повторное чтение после сохранения,
  ошибки видны пользователю, повторные нажатия блокируются.
- Различаются сохранённое разрешение Fusion и scope_active; поле scope_active
  не объявляется доказательством улучшения или фактической работы генерации.
- Fusion/Boost/preference не меняются при выключенном Autopilot. Отключение
  Autopilot не останавливает другой активный режим Governor.
- Удаление переменной темы возвращает обычную панель GFG в течение двух секунд.
  Никаких поддельных данных Steam или картинок макета поверх интерфейса.
- Существующий безопасный ThemeInstaller устанавливает GFG-SteamOS из настроек.
  Установка не включает тему, не меняет другие темы и не скачивает зависимости.
  Старый инжектор имеет отдельную кнопку отключения; его статус не считается
  состоянием CSS Loader. Статус «styles detected» относится только к текущему окну.

## Что ещё не выполнено

| Экран | Реализованная основа | Осталось до макета |
|---|---|---|
| Главная | Art Hero + оформление GFG | верхняя навигация, отдельная кнопка запуска, точная геометрия |
| Библиотека | оформление нативных вкладок/обложек | сетка 4×2 с корректной виртуализацией и фокусом |
| Игра | Clean Gameview + оформление | встроенная панель GFG на странице, точная композиция |
| Quick Access | оформление + панель плагина Decky | объединение системных настроек и GFG в один экран |
| Настройки | цвета и выделение нативных элементов | проверка селекторов/размеров на Deck |
| Загрузки | оформление нативных строк и прогресса | компоновка активной загрузки как в макете |
| Меню Steam | оформление нативного меню | точные размеры, фон, состояние запущенной игры |
| Клавиатура | правила для семейства virtualkeyboard | подтверждение селекторов, IME и раскладок на Deck |

Таким образом, наличие восьми CSS-файлов НЕ означает реализацию восьми макетов 1:1.
Точная компоновка и вставка новых компонентов требуют проверки настоящего Steam UI.
Доступ к Deck/CEF в этой среде по-прежнему отсутствует. Нельзя подтвердить контроллер,
Steam/QAM, сон/пробуждение, фокус виртуальной сетки, версии зависимостей, утечки или
визуальные допуски на OLED. Следующий обязательный этап — доступ к реальному Gaming Mode.

## Проверка и установка

Команды проверки: `node --test frontend/harness/shell-actions.test.mjs`,
`node frontend/harness/cssloader.mjs`, `node frontend/harness/smoke.mjs`,
`python3 -m unittest discover -s tests -p test_theme_installer.py`.
Тесты браузера проверяют реальные компоненты GFG с подставными ответами RPC,
а не совместимость с Steam. CSSOM-проверка не подтверждает совпадение селекторов Steam.

Сборка отдельной темы: `python3 scripts/package_cssloader.py`.
ZIP содержит только тему и README, не полный плагин и не сторонние зависимости.
SHA-256 записывается рядом. Полный кандидат GFG собирается существующим workflow
candidate-shell из того же коммита; отдельная тема публикуется только как CI artifact.
Релиз и merge запрещены до завершения реальной приёмки.

Установка: Settings → GFG theme → Disable legacy GFG appearance → Install CSS Loader
theme; затем CSS Loader → Refresh → GFG SteamOS → согласиться с зависимостями.
Перед переключением сохранить текущий CSS Loader profile. Альтернатива: распаковать
ZIP в ~/homebrew/themes, сохраняя путь GFG-SteamOS/theme.json.
Возврат: отключить тему и её зависимости, восстановить предыдущий профиль CSS Loader.
