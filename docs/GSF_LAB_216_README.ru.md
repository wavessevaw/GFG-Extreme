# GFG Extreme 2.1.6 + GSF LAB.2 (экспериментальная сборка)

**Это самостоятельная проверочная сборка, а не релиз и не подтверждение запуска на Steam Deck.**

## Что исправлено по реальной телеметрии Steam Deck
- Новая исходная реализация планировщика Vulkan GSF: распределяет промежуточные кадры по доступным 90-Гц слотам вместо безусловного требования отображать середину исходного интервала. При 60 реальных FPS и 90 Гц целевой **предел допуска** составляет около 30 синтетических WSI-передач в секунду, а не 60; при 42 реальных FPS возможно до 42 дополнительных слотов.
- Установщик помещает единственный Vulkan JSON-манифест и ссылку на библиотеку в специальный каталог \`vulkan-layers/\`, отдельно от служебного \`MANIFEST.json\`. Это устраняет ошибку сканирования данных загрузчиком.
- Запускатель отклоняет буквальный \`%command%\`, не создавая ложную диагностику падения Vulkan.
- Исходник и 64-битная библиотека **пересобираются в GitHub Actions из точно закреплённого коммита**, а не копируются из предыдущего \`internal.10\`. Контрольная сумма новой библиотеки и идентификатор исходников проверяются.

**Это изменение политики допуска и доставки кадров, а не доказательство удвоения FPS на OLED.** Длительные задержки WSI, пропуски GPU deadline, качество интерполяции и аппаратный scanout требуют повторного испытания. Никакого слияния в стабильный \`main\` автоматически нет.

## Что внутри
- Полный официальный пакет **2.1.6** со всеми тремя MAKO Flatpak, GFG Shell, Frame Fusion, Frame OS/HUD, Governor, Frontend и исходной конфигурацией.
- Отдельно добавленный независимый Vulkan Layer GSF из нового исходного коммита **internal.11** (SHA-256 сверяется при сборке).
- Скрипт `bin/gfg-native/gfg-gsf-lab.sh`, включающий GSF **только по явному запросу**. Установка этого ZIP сама по себе НЕ устанавливает Vulkan Layer глобально и НЕ активирует генерацию GSF.
- Важное ограничение: UI стабильного GFG 2.1.6 не получил новый переключатель GSF. Переключение только через параметры запуска Steam для одной игры.

## Порядок безопасной проверки

Перед опытом убедиться, что исходная игра запускается с чистыми параметрами Steam и без старого GSF-префикса. Сохранить стабильный ZIP 2.1.6 для возврата.

В Desktop Mode на устройстве после установки LAB ZIP один раз выполнить в Konsole:

```bash
bash "$HOME/homebrew/plugins/GFG-Extreme/bin/gfg-native/gfg-gsf-lab.sh" --install
```

Это размещает GSF только в каталоге пользователя `~/.local/share/gfg-native` и создаёт `~/.local/bin/gfg-native`. Установщик проверяет контрольные суммы и делает откатную копию предыдущего native-компонента.

Затем **начать с полностью выключенного GSF**. В параметрах запуска одной игры Steam:

```bash
bash "$HOME/homebrew/plugins/GFG-Extreme/bin/gfg-native/gfg-gsf-lab.sh" --off %command%
```

После подтверждённого запуска игры по очереди проверять режимы (НЕ раньше):

```bash
bash "$HOME/homebrew/plugins/GFG-Extreme/bin/gfg-native/gfg-gsf-lab.sh" --x2 --diagnose %command%
```

```bash
bash "$HOME/homebrew/plugins/GFG-Extreme/bin/gfg-native/gfg-gsf-lab.sh" --x3 --diagnose %command%
```

При падении игры **вернуть старые параметры запуска без GSF или режим --off**. Для полностью чистого исходного теста удалить запускатель из параметров игры: именно этот вариант является исходным контрольным запуском.

Диагностика native: `~/.local/state/gfg-native/diagnostics`. При отправке логов проверить пути/частные сведения внутри.

## Почему размер ближе к 88–90 МБ

Исходный экспериментальный ZIP Codex (~8,47 МБ) был собран из `git archive` и GSF-компонента и не включал тяжёлые бинарные payload-ы стандартного release-конвейера. Эта LAB-сборка начинается с **точного официального ZIP v2.1.6**, сохраняет все его файлы и добавляет GSF. Сборка прерывается, если отсутствует хоть один из трёх Flatpak, Shell, Fusion или слои Frame OS/HUD.

## Что ещё НЕ проверено

- Настоящий запуск SteamOS/Proton/RADV с этим новым пакетом.
- 32-битные процессы Proton: GSF содержит 64-битный Vulkan Layer. Если обязательный Vulkan Layer будет загружаться 32-битным процессом, Vulkan инициализация может отказать. Обозначение `--off` не меняет остальные Vulkan Layers.
- Корректное взаимодействие Gamescope WSI / Steam Runtime и работа 30→90 физических, различных кадров.
- Работа HDR на устройстве, задержка ввода, реальные фреймтаймы и расход энергии.

**Важно:** успешный CI, проверка целостности ZIP и отсутствие падений в тестах Bash не подтверждают совместимость Vulkan Layer с настоящей игрой на Steam Deck.

## Возврат

Убрать GSF-префикс из параметров запуска игры и при необходимости переустановить официальный стабильный 2.1.6. Для отката отдельно установленного native-компонента:

```bash
bash "$HOME/homebrew/plugins/GFG-Extreme/bin/gfg-native/rollback.sh"
```

Стандартный GFG 2.1.6 не должен автоматически вызывать GSF. Откат native-компонента не требуется для запуска обычной игры без GSF, но полезен для восстановления предыдущей экспериментальной версии.
