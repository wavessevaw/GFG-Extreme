# GFG Extreme UI Redesign — Beta 1

The old gfg.4 UI remains a functional reference, not a visual reference.

Beta 1 changes the information hierarchy so the first screen prioritizes only:

- Governor state and 90/60 target;
- Real -> multiplier -> Output cadence;
- current observed TDP;
- recommended Operating Point;
- one Governor enable/disable control.

Pipeline Inspector, detailed runtime status, feature settings, Configuration Journal, launch instructions and expert configuration remain available under `Advanced Controls` rather than being rendered simultaneously.

The Redline language is retained but toned down: near-black surfaces, white/grey typography, and red as an active/status accent rather than a border around every object.

Later Beta work should split Advanced into contextual Frame Generation, Scaling, Pipeline, Activity and Developer screens. Beta 1 intentionally avoids deleting existing controls before their replacement surfaces are complete.
