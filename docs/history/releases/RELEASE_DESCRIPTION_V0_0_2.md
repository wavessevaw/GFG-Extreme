## GFG Extreme Decky: Governor v0.0.2 (pre-release)

Governor pre-release.

- New one-button interface with touch and controller support
- Automatic target for the screen (OLED 90, LCD 60, dock 60)
- Renderer-confirmed operating points with rollback
- In-game overlay and copyable launch command

### Install
Download `GFG-Extreme-Governor-v0_0_2.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.
