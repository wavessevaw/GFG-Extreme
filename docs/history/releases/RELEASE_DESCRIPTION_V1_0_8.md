## GFG Extreme 1.0.8

Bug fixes and improvements.

- More reliable TDP restore when a game exits or the plugin reloads
- TDP control is detected even if it becomes available after the plugin starts
- A log recording in progress is saved when the plugin reloads
- Text settings are saved on Enter instead of on every keystroke
- Interface fixes

### Install
Download `GFG-Extreme-v1_0_8.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.
