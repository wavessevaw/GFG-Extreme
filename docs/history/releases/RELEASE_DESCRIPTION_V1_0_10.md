## GFG Extreme 1.0.10

Bug fixes and improvements.

- Quality mode lowers TDP again after a heavy scene is over
- Quality mode no longer drops a working setting after a single hitch
- TDP set by another tool is no longer overwritten when GFG stops
- Text settings are kept when leaving the page before pressing Enter
- Stability fixes

### Install
Download `GFG-Extreme-v1_0_10.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.

### Verify your download
SHA-256 of the zip: `<sha256>` (see `SHA256SUMS.txt`).
