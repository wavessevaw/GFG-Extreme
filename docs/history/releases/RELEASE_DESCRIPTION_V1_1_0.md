## GFG Extreme 1.1.0

New: render scale in Battery and Balanced.

- In heavy scenes GFG lowers the render resolution to 90% or 80% before spending more power, and returns to full resolution when the scene allows
- Requires Settings → Scaling → Scale-ready launch (then restart the game); Details shows whether it is active
- Bug fixes and improvements

### Install
Download `GFG-Extreme-v1_1_0.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.
