## GFG Extreme 1.0.0

First official release.

- Battery, Balanced and Quality modes
- Automatic target, frame generation and TDP management
- In-game overlay, Check setup and log recording

### Install
Download `GFG-Extreme-v1_0_0.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.

### Verify your download
SHA-256 of the zip: `<sha256>` (see `SHA256SUMS.txt`).
