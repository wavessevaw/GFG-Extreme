## What's New in 3.4.3

- **Faster Benchmark:** A 15-second measurement budget replaces the lengthy per-TDP windows.
- **Fewer TDP jumps:** Descending 2 W steps without repeatedly returning to maximum power; final check of the selected point.
- **Safer results:** Brief missing Gamescope telemetry no longer cancels the scan. Unconfirmed results cannot be applied.
- **Engine unchanged:** Uses the same GSF Kedavra 1.6.2 runtime and frame-generation algorithms as 3.4.2.
