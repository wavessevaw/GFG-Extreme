# GFG Extreme 3.3.0

**GFG Extreme 3.2.2 + GSF Kedavra 1.5.0.**

- Более чёткие детали при быстром, достоверно восстановленном движении благодаря адаптивному уменьшению размытия.
- Сохранены интерфейс, настройки и функции стабильной версии 3.2.2.
- Новый алгоритм не добавляет GPU-проходов, текстурных выборок или буферов.

В программном Vulkan-тесте быстрой панорамы ошибка RGB снизилась примерно на 80%, PSNR вырос на 3,68–4,20 дБ. Это результаты тестовой сцены, не замеры игр на Steam Deck. Квадратные артефакты при сложных поворотах ниже 30 FPS остаются известным ограничением. Аппаратная валидация производительности и задержки Steam Deck не заявляется.

**Установка:** ZIP через Decky Loader → обновить движок в Setup → перезагрузить устройство. Для возврата сохраните установочный ZIP 3.2.2.
