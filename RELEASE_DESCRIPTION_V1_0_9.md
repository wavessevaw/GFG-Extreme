## GFG Extreme 1.0.9

Bug fixes and improvements.

- Profiles are no longer lost when the engine is reinstalled over a configuration it cannot read; the old file is kept as a backup
- Profile settings are saved safely even if the Deck loses power during a save
- Automatic Dock: renaming or deleting a profile while docked works correctly
- Automatic Dock no longer treats the handheld screen as an external display when the display information is missing
- Minor fixes

### Install
Download `GFG-Extreme-v1_0_9.zip` below and install it through Decky Loader (*Install from zip*) over your current version; settings and profiles are kept.

### Verify your download
SHA-256 of the zip: `<sha256>` (see `SHA256SUMS.txt`).
