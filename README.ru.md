# GFG Extreme Decky

**Нажмите Run, и Steam Deck выдаст плавную и экономную картинку.**

## Чем это хорошо

Большинство инструментов генерации кадров дают стену переключателей и оставляют вас гадать. **GFG Extreme Decky делает наоборот: один красивый экран и одна кнопка Run.**

| | |
|---|---|
| **Одна кнопка** | Нажмите **RUN**. Governor определит устройство, выберет цель, запустит движок и будет управлять им, пока вы играете. |
| **Знает ваш экран** | **Steam Deck OLED → 90 FPS**, **Steam Deck LCD → 60 FPS**, **Dock / внешний монитор → 60 FPS**. Ручная настройка не нужна. |
| **Три режима** | **Battery** (сначала минимальный TDP, идеально 9–11 Вт, реальных FPS не меньше 24), **Balanced** (старт с 45 реальных FPS и 12 Вт, никогда ниже 30 реальных FPS и не выше обычного диапазона мощности Deck) и **Quality** (сначала меньше сгенерированных кадров, затем снижение TDP). Выбирается на главном экране. |
| **Подстраивается всю сессию** | Частота кадров проверяется каждую секунду: игре, которой не хватает мощности, ватты возвращаются примерно за 2 с, а пока игра держится, каждые 45 с пробуется на 1 Вт меньше. Множители от нативного до ×3 с шагом 0.25 (Battery может уходить глубже только как крайняя мера), каждый подтверждается по данным рендерера и откатывается, если не держится. |
| **Помнит ваши игры** | Когда точка удержалась, её режим и TDP сохраняются для профиля, цели по FPS и режима, и следующая сессия стартует с них, а не с поиска. |
| **Видит устройство** | Температура и её тренд, нагрузка GPU и самого занятого ядра CPU, вентилятор, потребление от батареи и frametime (p95/p99, статтер) читаются из системы. Вердикт в одну строку (упирается в GPU, в CPU, в лимит TDP, перегрев, статтер) виден на главном экране. Игре, упирающейся в CPU, точки с пониженным масштабом рендера не предлагаются. |
| **Не трогает ваш профиль** | Сохранённый профиль **никогда не изменяется**. Governor работает через временный оверлей настроек и всегда возвращает исходное состояние. |
| **Безопасно по конструкции** | Никакого разгона, никакого повышения лимита мощности, никогда не ×4/×5 автоматически; отступает, если TDP или конвейер занят другим инструментом. |
| **Честная оценка усилий** | **GFG Effort** (Easy · Medium · Hard · Nightmare) показывает, насколько тяжело работает движок, и появляется только когда стабилизируется, чтобы не мигать. |
| **Компактный оверлей в игре** | Одна тонкая строка: FPS, время кадра, множитель, реальные → выходные FPS, масштаб рендера, TDP, время работы от батареи, effort. |
| **Всё остальное на месте** | Профили, правила для игр, поддержка Flatpak, Pipeline Inspector, журнал конфигурации и все параметры движка остаются в разделе *Settings*. |

## Как думает Governor

1. **Определяет** устройство (OLED, LCD, Dock) и выбирает цель.
2. **Вспоминает**: если в эту игру уже играли в этом режиме, стартует с точки и TDP, которые держались.
3. **Измеряет** реальную частоту кадров по телеметрии движка каждую секунду.
4. **Выбирает и подтверждает**: каждая точка подтверждается по реальным данным и откатывается, если не держится.
5. **Подстраивается**: сразу добавляет ватты или глубину множителя, если игре не хватает, и пробует на 1 Вт меньше каждые 45 с, пока всё держится.
6. **Освобождает** всё чисто при Stop, выходе из игры или смене профиля. Сохранённый профиль не изменяется.

Каждое решение пишется в журнал, который можно посмотреть.

## Что-то не работает? Запишите лог

Settings → Diagnostics → **Record log**, поиграйте минуту-две, **Stop and save log to Desktop**. На рабочем столе Steam Deck появится zip, а на экране будет список того, что показывает лог (например «рендерер не писал диагностику», «большую часть времени на паузе»). В zip: `summary.txt`, таймлайн раз в секунду, диагностика рендерера, решения Governor, самопроверка всех предпосылок и сгенерированный лаунчер. На ПК тот же вердикт печатает `python3 tools/gfg_log_report.py <zip>`.

## Установка и запуск

Нужен [Decky Loader](https://decky.xyz/) на SteamOS и **обычная публичная версия** [Lossless Scaling](https://store.steampowered.com/app/993090/Lossless_Scaling/) из Steam для генерации кадров и масштабирования LS1.

1. Установите ZIP GFG Extreme Decky через Decky Loader.
2. Откройте GFG Extreme и нажмите **Install engine** (одного ZIP для установки движка недостаточно).
3. Укажите в параметрах запуска игры в Steam:

```text
/home/deck/.local/bin/gfg %command%
```

4. Запустите игру и нажмите **RUN**. GFG подключается к уже запущенной игре; перезапуск нужен только игре, запущенной до установки этой версии (или без команды запуска).

Старая команда `mako-run` продолжает работать как псевдоним. Для Heroic, Lutris, EmuDeck и других Flatpak-приложений откройте **Settings → System** и включите GFG для приложения (расширение среды и доступ подготавливаются автоматически).

## Остальные возможности

- **Профили** для игр и процессов, выбираются автоматически по Steam app ID или имени процесса.
- Генерация кадров через **GFG Engine**, **OptiScaler**, **Game Native** или **Off**; пространственное масштабирование и шейдеры независимы. Внешние бэкенды работают в режиме **только наблюдения**, Governor с ними не конфликтует.
- **Pipeline Inspector**: сравнивает состояния *Saved*, *Effective*, *Governor runtime* и *Actual*, проверенные по работающему процессу.
- **Журнал конфигурации** с безопасным по схеме откатом.
- Совместимость с Gamescope WSI, MangoHud, встроенные шейдеры vkBasalt (резкость, сглаживание, освещение).
- Расширения среды Flatpak и доступ для отдельных приложений.

## Статус

**Бета (Governor v0.0.16).** Движок принятия решений, работа с оверлеем и правила безопасности покрыты автоматическими тестами (в том числе тестами, которые запускают настоящий сгенерированный скрипт запуска в bash). Проверка на реальных Steam Deck запланирована на интеграционный релиз v0.0.10, поэтому возможны шероховатости. Известные ограничения перечислены в заметках к релизу.

## Преемственность и благодарности

GFG Extreme Decky — **продолжение наработок MAKO и LSFG**: он наследует [Decky LSFG-VK Experimental](https://github.com/eugeniosegala/decky-lsfg-vk-experimental) под отдельным именем продукта и пакета, а встроенный движок основан на общественном проекте MAKO, приносящем в Linux генерацию кадров LSFG, пространственное масштабирование и шейдерные эффекты. Большая благодарность авторам MAKO и lsfg-vk.

GFG Extreme не содержит и не распространяет Lossless Scaling. Имена файлов `mako-*`, идентификаторы слоёв Vulkan, пути конфигурации и имена RPC из upstream сохранены там, где их изменение нарушило бы совместимость рендерера.
